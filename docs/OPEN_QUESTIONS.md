# Preguntas abiertas

## Bloqueantes antes de implementar

1. Confirmar versión estable de Godot y entorno de exportación Android.
2. Definir si el gesto conecta una cadena libre ortogonal o intercambia fichas adyacentes. La hipótesis actual es cadena ortogonal.
3. Confirmar orientación bloqueada en vertical.

## Validables con prototipo

- ¿5 × 5 ofrece suficiente espacio?
- ¿Tres carriles y tablero compiten demasiado por atención?
- ¿Autoapuntar se siente justo?
- ¿Tres minutos es el ritmo correcto?
- ¿Las recetas mixtas agregan estrategia o confusión?
- ¿Debe pausarse el avance mientras se resuelve una combinación?

## Después del prototipo

Nombre definitivo, dirección artística final, iOS, monetización, analítica, metaprogresión, eventos y localización adicional.
